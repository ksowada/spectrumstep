SpectrumStep – Multi-Space Gradient & Contrast Generator

Create precise discrete color gradients and evaluate text contrast in real time across HSL, HSV, and RGB color spaces.

How to use SpectrumStep

1. Configure Colors: Toggle between HSL, HSV, and RGB spaces for each color picker. Adjust sliders or fine-tune components directly using numeric inputs.

2. Invert & Copy: Invert color channels or sync settings instantly using the RGB-Invert, HSL-Invert, or C2 use C1 utility buttons.

3. Set Steps & Overdrive: Define the exact number of discrete gradient steps and fine-tune channel intensity using the Overdrive control.

4. Color Spaces & Contrast: Switch the interpolation space (HSL, RGB, HSV) and test legibility with custom light, dark, or user-defined background and text combinations.

5. Export CSS: Copy the ready-to-use linear-gradient CSS code snippet generated at the bottom.

Description of tool-elements

HSL stands for Hue, Saturation, and Lightness and is often also called HLS. Hue defines the color, Saturation determines its intensity, and Lightness controls its brightness, ranging from black to white. HSV stands for hue, saturation, and value, and is also often called HSB. See wikipedia: HSL and HSV

  • C1 and C2: Enter HEX or decimal RGB, HSL or HSV values, or select colors using the color picker. Customize your color with range sliders for each color component in HSL, RGB and HSV color space, the slider is colored to actual selection. You may also enter HEX or HSL values by text.
  • Steps: Choose the number of intermediate colors in your palette or gradient. Generate smooth color gradients between 2 colors with a configurable number of steps to create custom color palettes and smooth color transitions.
  • RGB,HSL or HSV: Select the color space used for interpolation between the two colors.
  • Hue inversion: Reverse the hue direction to create alternative color transitions. Might be good to swap colors between dark and light background.
  • Overdrive: Extend the color range beyond the two base colors.
  • Text contrast: Explore text and background color combinations.
  • Back contrast: Alternatively you make a gradient of text-color and you may choose the static background-color for the whole gradient.
  • Gradient output: Generate CSS linear gradients and copy HEX color values for use in websites, GIMP, Inkscape, and other graphics applications. Create color scales for website themes, buttons, backgrounds, and other UI elements. Save and load your color selections directly in your browser without cookies.
  • Contrast ratio: The tool displays the contrast ratio for each color, helping you explore readable text and background combinations.
  • Light and dark mode: Invert colors to explore alternative color schemes.
  • Save and load: Store and restore your color selections locally in your browser without cookies.
