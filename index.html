HSL Mixer

Your colors can be mixed easily. Use RGB values in hex, or mix your colors using HSL. This creates a color palette that is easy to configure. Change the number of rows, RGB or HSL. The hue can be adjusted effortlessly.

This calculator creates color transitions. In the HSL space, interpolation happens between two colors and also in the inverse direction. You receive the RGB values in hex for use in CSS or for graphics software such as the image editor GIMP or the drawing program INKSCAPE.

HSL means the following:

  • H stands for Hue. Hue is the color tone. It refers to a rainbow. In a rainbow, all colors of white light are spread out.
  • S stands for Saturation. Saturation is the intensity of the hue. Without intensity, the hue becomes gray.
  • L stands for Lightness. Lightness is the brightness. Full brightness is white, no brightness means black, as in absence of light.

This is how you operate the tool:

  • C1 is the base color. It can be entered as an RGB hex value or selected with the color button, which opens a color picker.
  • C2 is the second color used for mixing. Interpolation happens between these two colors in HSL. This allows you to create beautiful intermediate shades.
  • You can also enter colors in HSL using sliders or text input.
  • You can save and load colors. It works without cookies. The information is stored in the browser. Simply do not delete your browser data, and your color selection will remain available.
