SpectrumStep – Multi-Space Gradient & Contrast Generator

Create precise discrete color gradients and evaluate WCAG 2.1 text contrast in real time across HSL, RGB, HSV, OKLab, and OKLCH color spaces.

How to use SpectrumStep

1. Configure Endpoint Colors: Switch each endpoint independently between cylindrical HSL, additive RGB, cylindrical HSV, perceptual Cartesian Oklab, and perceptual cylindrical Oklch color models (). Adjust live-rendered channel sliders, enter exact numeric and hexadecimal values, or click any channel button in the first column (HSL / RGB / HSV / lab / lch) or double-click its range slider to fix that component and pick the other two on a 2D color plane ().

2. Transform & Sync Endpoints: Generate random 24-bit sRGB colors (Random), compute the sRGB complement (RGB-Invert), reflect lightness while preserving hue and saturation (HSL-Invert), or clone colors across endpoints (Copy).

3. Set Steps & Overdrive: Define the number of equidistant interpolation steps (2–16) and optionally extrapolate steps beyond both base colors using Overdrive (0–16). If extreme overdrive produces saturated colors that hit gamut boundaries, duplicate clamped steps are automatically pruned to keep the palette meaningful.

4. Interactive Swatch Position Slider: Fine-tune each swatch's interpolation position using the dedicated slider bar between the palette swatches and continuous CSS preview. Drag a handle across the full 0%–100% range; swatches can overtake one another and the percentage badge updates while dragging. Double-click any handle to reset all positions to the defaults defined by Steps and Overdrive. These handles only adjust swatch interpolation positions; they do not copy colors or CSS. Exact 0% and 100% positions evaluate to Color 1 and Color 2 without conversion drift.

5. Interpolation Space, Direction & Hue Path: Choose the mixing space (HSL / RGB / HSV / Oklab / Oklch), spatial direction (), hue arc (shorter vs. longer), and toggle contrast info visibility (). Evaluate legibility against static foreground text or static background colors.

6. Export, Share & Copy: A dedicated indicator line under the gradient swatches clearly marks Color 1 and Color 2 with small, monochromatic text and indicates the core gradient belonging to the corner colors. Click any swatch in the discrete palette or its corner marker to copy its #RRGGBB hex code, click the continuous gradient bar to copy the ready-to-use CSS linear-gradient(...) declaration using native CSS color space interpolation, or copy the browser URL to share or bookmark your exact palette configuration.

Color Spaces: RGB, HSL, HSV, OKLab, and OKLCH

HSL (Hue, Saturation, Lightness) and HSV / HSB (Hue, Saturation, Value / Brightness) are cylindrical-coordinate transformations of the additive sRGB color model (Wikipedia: HSL and HSV). While intuitive for basic adjustments, neither HSL nor HSV is perceptually uniform—changing hue at a constant HSL lightness produces dramatic jumps in perceived brightness (for example, pure yellow appears much brighter than pure blue).

OKLab and its cylindrical counterpart OKLCH (designed by Björn Ottosson and standardized in CSS Color Level 4) model human visual perception so equal numerical steps correspond closely to equal perceived color differences:

  • OKLab (l, a, b): Represents colors using perceptual Lightness l (0–100%) and two opponent Cartesian axes: a (green −0.4 to red +0.4) and b (blue −0.4 to yellow +0.4). Interpolating linearly in OKLab produces smooth, natural transitions without the muddy gray midpoints common in sRGB or the brightness spikes of HSL.
  • OKLCH (l, c, h): Expresses OKLab in polar coordinates using perceptual Lightness l (0–100%), Chroma c (0 neutral gray to 0.4 vivid colorfulness), and Hue angle h (0°–360°). OKLCH is ideal when you want predictable lightness and vividness across hues or when building accessible UI color ramps.

What happens when you convert an out-of-gamut color to HEX? (Gamut Mapping)

Unlike HSL and HSV—which are mathematical re-mappings of the sRGB cube—OKLab and OKLCH can describe colors across the entire human visual gamut, including ultra-vivid colors that cannot be displayed on standard sRGB monitors or encoded as 24-bit #RRGGBB HEX values. Out-of-gamut coordinates can occur both when picking high chroma values manually and when interpolating in OKLCH between two in-gamut colors.

Reduce the chroma until the color fits: Suppose the desired color is too vivid for sRGB. Instead of naively clamping individual R, G, and B channels (which distorts both hue and perceived lightness), SpectrumStep gradually reduces the color's chroma via binary search while holding lightness and hue constant until the color can be represented within the sRGB gamut:

By preserving perceptual lightness (l) and hue angle (h) while reducing chroma (c, or proportionally scaling a and b in OKLab), you obtain a much closer visual match to the intended color and preserve consistent WCAG contrast ratios. This process is called gamut mapping. While more sophisticated algorithms (such as CSS Color 4 ΔEOK gamut mapping) are possible, chroma reduction at constant lightness and hue is a fast, predictable, and visually faithful method.

Technical Function Description

  • Light and Dark Theme: Toggles the surrounding UI luminance between light and dark surfaces so you can judge color appearance and simultaneous contrast accurately.
  • Color 1 and Color 2 Input Models (HSL, RGB, HSV, Oklab, Oklch): Each endpoint supports 6-digit or 3-digit shorthand HEX codes (#RGB → #RRGGBB), native color picking, and high-precision sliders (0.1° / 0.1% resolution in HSL/HSV, 8-bit 0–255 in RGB, 0.001 resolution for OKLab a/b and OKLCH c) with dynamic gradient tracks showing the effect of each parameter. The first column displays the active model's component identifiers (H/S/L, R/G/B, H/S/V, lowercase l/a/b, or lowercase l/c/h).
  • H / S / L R / G / B H / S / V l / a / b l / c / h 2D Color Plane Picker Popup: Clicking any channel button in the first column or double-clicking any channel's range slider fixes that color component and opens a 2D color plane directly below the selected row, aligned to the exact width of the channel range slider and sized so it never overlaps the gradient swatches below. Dragging across the plane selects the remaining two components simultaneously—first remaining channel along X (left → right: min → max) and second along Y (bottom → top: min → max)—while updating the gradient palette in real time.
  • Random Endpoint Color: Generates a uniform random 24-bit sRGB color (R, G, B ∈ [0, 255]) for rapid palette exploration.
  • RGB-Invert (Complement): Inverts all three sRGB channels (255 − R, 255 − G, 255 − B), rotating hue by 180° and inverting lightness simultaneously.
  • HSL-Invert (Lightness Reflection): Reflects lightness across the midpoint (L' = 100% − L) while keeping Hue and Saturation constant—ideal for converting UI tokens between light and dark themes.
  • Copy Endpoint Color: Transfers the exact hexadecimal color from Color 1 to Color 2 or from Color 2 to Color 1 as a starting point for monochromatic or analogous variations.
  • Steps & Overdrive Extrapolation: Steps divides the interval between Color 1 and Color 2 into N equidistant stops. Overdrive extends the linear interpolation parameter below 0 and above 1, extrapolating outer shades and tints with channel clamping, modular hue wrapping, and chroma-reduction gamut mapping. If extreme overdrive produces saturated colors that hit the gamut boundaries, duplicate clamped swatches are automatically pruned to keep the palette meaningful.
  • Interactive Multi-Pos Gradient Slider Bar: Positioned directly between the discrete swatches and continuous CSS linear-gradient preview, this thin track features circular knobs matching each swatch's position. Drag or keyboard-navigate a handle across the entire 0%–100% gradient span; handles can overtake each other. Movement recalculates the corresponding swatch color in real time, with exact endpoint colors at 0% and 100%. Double-click any handle to restore the default linear positions determined by Steps and Overdrive. The slider adjusts swatch positions and does not copy content.
  • Color 1 & Color 2 Swatch Markers: A dedicated line placed directly under the gradient swatches marks the corner colors (Color 1 and Color 2) using small, monochromatic indicator text and a subtle connecting baseline, clearly distinguishing the gradient belonging to the corner colors from any outer overdrive stops and enabling one-click HEX export.
  • Gradient Space (HSL, RGB, HSV, Oklab, Oklch): Determines the coordinate system used for linear interpolation between endpoints and updates the continuous CSS preview bar to use native CSS Color 4 gradient interpolation (in oklab, in oklch shorter|longer hue, in hsl shorter|longer hue). Endpoint colors are preserved without rounding loss.
  • Gradient Direction: Orbits the palette layout and CSS gradient vector across all four cardinal directions (Right 90deg, Down 180deg, Left, and Up).
  • Hue Interpolation Way (Shorter / Longer): In cylindrical spaces (HSL, HSV, and OKLCH), shorter interpolates along the minor arc (|ΔH| ≤ 180°, CSS shorter hue), whereas longer traverses the major arc (|ΔH| ≥ 180°, CSS longer hue) across the full spectrum.
  • Contrast Info Visibility (Show / Hide): Toggles the display of WCAG contrast ratios and compliance badges on the palette swatches, allowing a distraction-free view showing only the #RRGGBB hex values.
  • Text Color & Background Color Contrast Modes: Test either a fixed foreground text color (Black, White, or custom Color) over your generated background swatches, or apply the generated palette to text over a fixed background surface.
  • WCAG 2.1 Contrast Ratio & Badges: Computes relative luminance and contrast ratio (L1 + 0.05) / (L2 + 0.05) for every step, displaying real-time compliance badges: AAA (≥ 7:1), AA (≥ 4.5:1), AA+ (≥ 3:1 for large text), or Fail (< 3:1).
  • One-Click Clipboard Export: Click any swatch to copy its HEX code or click the continuous preview bar to copy the CSS linear-gradient snippet, confirmed with an instant toast notification.
  • Shareable Palette URLs: Synchronizes all active colors, channel values, interpolation settings, and contrast options into compact URL search parameters so custom palettes and gradients can be bookmarked or shared via link.
  • Automatic Session Persistence & Local User Store: Automatically retains your current workspace inputs in browser localStorage across page visits without cookies, and lets you save and load named palette presets on demand.
