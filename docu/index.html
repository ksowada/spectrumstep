SpectrumStep – Multi-Space Gradient & Contrast Generator

Create precise discrete color gradients and evaluate WCAG 2.1 text contrast in real time across HSL, HSV, and RGB color spaces.

How to use SpectrumStep

1. Configure Endpoint Colors: Switch each endpoint independently between cylindrical HSL, additive RGB, and cylindrical HSV color models (). Adjust live-rendered channel sliders, enter exact numeric and hexadecimal values, or click any channel button (HSL / RGB / HSV) to fix that component and pick the other two on a 2D color plane ().

2. Transform & Sync Endpoints: Generate random 24-bit sRGB colors (Random), compute the sRGB complement (RGB-Invert), reflect lightness while preserving hue and saturation (HSL-Invert), or clone colors across endpoints (Copy).

3. Set Steps & Overdrive: Define the number of equidistant interpolation steps (2–16) and optionally extrapolate steps beyond both base colors using Overdrive (0–16).

4. Interpolation Space, Direction & Hue Path: Choose the mixing space (HSL / RGB / HSV), spatial direction (), hue arc (shorter vs. longer), and toggle contrast info visibility (). Evaluate legibility against static foreground text or static background colors.

5. Export, Share & Copy: Click any swatch in the discrete palette to copy its #RRGGBB hex code, click the continuous gradient bar to copy the ready-to-use CSS linear-gradient(...) declaration, or copy the browser URL to share or bookmark your exact palette configuration.

What are HSL and HSV?

HSL (Hue, Saturation, Lightness) and HSV / HSB (Hue, Saturation, Value / Brightness) are cylindrical-coordinate representations of the sRGB color model. Hue specifies the angular position on the color wheel (0°–360°), Saturation controls chromatic purity (0%–100%), Lightness spans from black (0%) through pure hue (50%) to white (100%), and Value controls illumination intensity from black (0%) to full brightness (100%). See Wikipedia: HSL and HSV.

Technical Function Description

  • Light and Dark Theme: Toggles the surrounding UI luminance between light and dark surfaces so you can judge color appearance and simultaneous contrast accurately.
  • Color 1 and Color 2 Input Models: Each endpoint supports 6-digit or 3-digit shorthand HEX codes (#RGB → #RRGGBB), native color picking, and high-precision sliders (0.1° / 0.1% resolution in HSL/HSV, 8-bit 0–255 in RGB) with dynamic gradient tracks showing the effect of each parameter.
  • H / S / L R / G / B H / S / V 2D Color Plane Picker Popup: Clicking any channel button in the first column fixes that color component and opens a 2D color plane directly below the selected row, aligned to the exact width of the channel range slider and sized so it never overlaps the gradient swatches below. Dragging across the plane selects the remaining two components simultaneously—first remaining channel along X (left → right: 0 → max) and second along Y (bottom → top: 0 → max)—while updating the gradient palette in real time.
  • Random Endpoint Color: Generates a uniform random 24-bit sRGB color (R, G, B ∈ [0, 255]) for rapid palette exploration.
  • RGB-Invert (Complement): Inverts all three sRGB channels (255 − R, 255 − G, 255 − B), rotating hue by 180° and inverting lightness simultaneously.
  • HSL-Invert (Lightness Reflection): Reflects lightness across the midpoint (L' = 100% − L) while keeping Hue and Saturation constant—ideal for converting UI tokens between light and dark themes.
  • Copy Endpoint Color: Transfers the exact hexadecimal color from Color 1 to Color 2 or from Color 2 to Color 1 as a starting point for monochromatic or analogous variations.
  • Steps & Overdrive Extrapolation: Steps divides the interval between Color 1 and Color 2 into N equidistant stops. Overdrive extends the linear interpolation parameter below 0 and above 1, extrapolating outer shades and tints with channel clamping and modular hue wrapping.
  • Gradient Space (HSL, RGB, HSV): Determines the coordinate system used for linear interpolation between endpoints. Endpoint colors are preserved without rounding loss.
  • Gradient Direction: Orbits the palette layout and CSS gradient vector across all four cardinal directions (Right 90deg, Down 180deg, Left, and Up).
  • Hue Interpolation Way (Shorter / Longer): In cylindrical spaces (HSL/HSV), shorter interpolates along the minor arc (|ΔH| ≤ 180°, CSS in hsl shorter hue), whereas longer traverses the major arc (|ΔH| ≥ 180°, CSS in hsl longer hue) across the full spectrum.
  • Contrast Info Visibility (Show / Hide): Toggles the display of WCAG contrast ratios and compliance badges on the palette swatches, allowing a distraction-free view showing only the #RRGGBB hex values.
  • Text Color & Background Color Contrast Modes: Test either a fixed foreground text color (Black, White, or custom Color) over your generated background swatches, or apply the generated palette to text over a fixed background surface.
  • WCAG 2.1 Contrast Ratio & Badges: Computes relative luminance and contrast ratio (L1 + 0.05) / (L2 + 0.05) for every step, displaying real-time compliance badges: AAA (≥ 7:1), AA (≥ 4.5:1), AA+ (≥ 3:1 for large text), or Fail (< 3:1).
  • One-Click Clipboard Export: Click any swatch to copy its HEX code or click the continuous preview bar to copy the CSS linear-gradient snippet, confirmed with an instant toast notification.
  • Shareable Palette URLs: Synchronizes all active colors, channel values, interpolation settings, and contrast options into compact URL search parameters so custom palettes and gradients can be bookmarked or shared via link.
  • Automatic Session Persistence & Local User Store: Automatically retains your current workspace inputs in browser localStorage across page visits without cookies, and lets you save and load named palette presets on demand.
